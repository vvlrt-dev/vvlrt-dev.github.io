# Web Portfolio — Jahondor O.

Front-end and Roblox developer based in Tashkent, Uzbekistan (UTC+5).

Three concept websites for fictional brands. Each is a single self-contained HTML file with vanilla CSS and JavaScript, fully responsive, with light and dark themes.

| Project | Type | Highlights |
| --- | --- | --- |
| [Tidewell](tidewell.html) | E-commerce landing page | Pack configurator with live pricing and subscription discount, sweat-rate calculator, FAQ |
| [Kazan & Tandoor](kazan.html) | Restaurant website | Filterable tabbed menu, live "open now" status, validated table-booking form |
| [Shiftbook](shiftbook.html) | SaaS landing page | Interactive rota with auto-fill, labor-cost summary, per-seat pricing slider |

Tech: HTML5, CSS (custom properties, grid, flexbox), vanilla JavaScript. No frameworks or build step.

All brands are fictional and were created as portfolio demos.
